# Methodology

## Data design
The project models 120 Delhi localities using normalized indices on a 0–100 scale.

### Core dimensions
- Income Index
- Population Density Index
- Online Grocery Index
- Delivery Accessibility Index
- Competition Index
- Transit Accessibility Index
- Demand Index
- Commercial Rent Index

## Modeling logic
Demand is modeled as a function of population density, income, online grocery propensity and delivery accessibility.

Expansion attractiveness combines:
- demand potential,
- digital adoption,
- operational feasibility,
- purchasing power,
- and the competitive gap.

## Limitations
This project is designed to demonstrate strategy/analytics thinking. The data is synthetic and should not be interpreted as actual market intelligence for Blinkit, Zepto or any other company.

The model should be recalibrated with observed order density, delivery SLA, store coverage, rent, customer acquisition cost and competitor data before commercial deployment.
